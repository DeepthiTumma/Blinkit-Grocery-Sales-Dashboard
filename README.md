# Blinkit Grocery Sales Dashboard

## Overview
Developed an interactive Power BI dashboard to analyze Blinkit grocery sales performance and business metrics.

## Tools Used
- Power BI
- Excel

## Key Features
- Sales Performance Analysis
- Outlet Performance Analysis
- Item Category Analysis
- Customer Rating Analysis
- KPI Monitoring

## Dashboard Insights
- Total Sales
- Average Sales
- Item Count
- Average Rating
- Outlet Size Analysis
- Location-wise Sales Analysis
